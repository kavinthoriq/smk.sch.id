# 🏫 SMK TI Dwiguna: Desain Website Sekolah

Desain antarmuka (UI) **website resmi SMK TI Dwiguna Depok**, dengan slogan **"Forging Future Mechanics"**. Desain dibuat di Figma dan mencakup tiga halaman utama: Beranda, Galeri, dan Kontak.

Repository ini berisi **file desain Figma** beserta **ekspor SVG** dari setiap halaman.

## 🚀 Cara Melihat Desain

**Lewat Figma**
1. Buka [figma.com](https://www.figma.com/) dan masuk ke akunmu.
2. Pilih **File → Import** (atau seret `smk_sch_id.fig` ke halaman Drafts).
3. Buka file tersebut untuk melihat dan mengedit semua halaman.

**Lewat SVG**
- Buka file `.svg` langsung di browser, atau seret ke Figma, Illustrator, atau Inkscape.
